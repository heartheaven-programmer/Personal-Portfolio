🐾 LOOKING BACK

My Final Reflection

What Web Development Taught Me

Looking back on this semester, Web Development has been an incredible journey of turning curiosity into code. Before taking this subject, I had limited experience creating websites. I quickly learned that building a website requires more than just writing code—it requires creativity, patience, logical thinking, and a lot of problem-solving.

My first activity, creating an interactive profile card, introduced me to the power of the Document Object Model (DOM). I learned how to use Vanilla JavaScript to listen for user actions—like clicking, typing, and hovering—and dynamically change the page's content and styles in response. It was exciting to see my code react instantly to user input.

My second activity pushed me to understand Asynchronous JavaScript. Using Promises and Promise.all to simulate loading a dashboard was challenging at first. There were times when my code didn't work as expected, and I had to carefully review my logic to find the errors. However, this taught me how to handle operations that take time to complete, which is a crucial skill for creating smooth, modern web experiences without reloading the page.

My third activity introduced me to the world of JavaScript libraries through jQuery. Building the Interactive Student Directory showed me how a library can simplify complex tasks. I learned how to handle multiple events like mousedown and mouseup, dynamically highlight table rows using :even and :odd selectors, and add smooth hide/show animations. This activity taught me that writing efficient code isn't just about knowing the syntax—it's about knowing the right tools to use.

Beyond our hands-on activities, we also explored the concept of AJAX (Asynchronous JavaScript and XML). I learned how AJAX allows webpages to communicate with a server in the background—fetching or sending data without requiring a full page reload. Understanding AJAX helped me realize how modern web applications, like social media feeds or live search bars, can update seamlessly behind the scenes.

Building this portfolio has been the culmination of everything I've learned. I combined HTML, CSS, and JavaScript to create a responsive, visually meaningful design using glassmorphism. I also implemented interactive features like the "Hide Biography" and "Read More" toggles, a dark mode option, and even a playful "Say Hi" modal.

My favorite part of this journey was discovering how JavaScript makes a webpage truly interactive and how different approaches—whether Vanilla JS, Promises, jQuery, or AJAX—can all work together to create beautiful results. For me, coding is not only about functionality—it's also about creating something visually meaningful, friendly, and enjoyable to use. My goal is to continue improving my programming skills and eventually build useful, beautiful websites as a professional Web Developer. 💗
